Portfolio site of Mahmoud Yosri: Flutter, FastAPI and machine learning.
Live at **https://mahmoudyosrimahmoud13.github.io**

- `argon.html`, `rubies.html`, `codenote.html` project case studies
- `assets/` stylesheet and script
- `img/` screenshots (WebP)
- `cv/` CV PDFs
