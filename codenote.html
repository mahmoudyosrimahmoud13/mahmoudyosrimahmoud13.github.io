the problem

Code doesn't fit in normal notes

Developers keep snippets in chats, screenshots, text files and note apps that break the formatting. I wanted one place where code stays readable, where a photo of code becomes real text, and where sharing a file from any app takes one tap.

What it does

1

Block-based notes

Each note is a stack of blocks, like a Jupyter notebook. Mix text, Markdown and code, then add, reorder and edit freely.

2

20+ languages highlighted

Python, Dart, C++, Go, Java, JavaScript, TypeScript, SQL, Kotlin, Bash, Arduino, assembly and more. Highlighting runs asynchronously, so long notes stay smooth.

3

Photo to code

Point the camera at code on a screen or in a book. Google ML Kit reads it on the device and turns it into an editable block.

4

Share from anywhere

CodeNote is a share target and an Open With handler for source files. It detects the language and builds a formatted note instantly, and shares notes back as .py, .txt or other files.

5

Tags, groups and chat

Group and tag notes by topic. The full version adds real-time group chat that keeps code formatting, plus cloud sync and notifications.
