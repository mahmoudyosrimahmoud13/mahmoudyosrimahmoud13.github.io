CodeNote

A notebook for code, notes and ideas. Text, code, Markdown and images live together in one note, with real highlighting, private AI and a keyboard-first design.

the problem

Code doesn't fit in normal notes

Developers keep snippets in chats, screenshots, text files and note apps that break the formatting. I wanted one place where code stays readable, where a question about my own notes gets a real answer, and where everything works from the keyboard, without sending my notes to anyone's cloud.

What it does

screenshots from the app
1

Notes made of blocks

  • Text, code, Markdown and image blocks in any order, in one note. Drag to reorder.
  • 58 languages highlighted, each with its logo, plus line numbers and JetBrains Mono.
  • Run HTML, CSS and JS right from a note, and a symbol bar for code on phones.
2

AI that respects your privacy

  • Explain code, find bugs, suggest improvements on any code block, and save the answer into the note.
  • Ask your notes: ask in plain words and get an answer from your own notes, with links to the notes it used.
  • Use Claude, any OpenAI-compatible API, or run fully offline with Ollama or LM Studio, found automatically. Off until you set it up.
3

Built for the keyboard

  • Command palette (Ctrl+K) for every action, note and folder.
  • GitHub Gist import and export, and code shared as images.
  • Share into CodeNote from any Android app: a .py or .sql file becomes a code block with the right language.
4

Templates and organizing

  • Templates for a bug report, dev log, LeetCode problem, meeting notes or API endpoint, or save any note as one.
  • Folders that preview what's inside, tags, pins, archive, search across code, and reminders as real notifications.
5

Your notes are safe

  • Backup and restore every note, folder and image in one .codenote file. Restoring merges and never deletes.
  • Daily backup to any folder on desktop, so Dropbox, Syncthing or a Git repo can sync it.
  • Trash keeps notes for 30 days, and every swipe has Undo.
